## 0. THE ANSWER IN SIX LINES

1. **Every pair on posts_show that carries a measured footprint is an
   OR-sharing licence.** Strict confinement licenses **700** pairs, and all 42
   decisions that represent their 258 gate classes have an **EMPTY** footprint
   (vacuously confined) — against 71 of the 123 decided decisions whose
   footprint is non-empty. The OR licence adds **2 001** pairs and *those* are
   the ones with content.
2. On one corpus (the booked P30C/P31CTLE list, 48 497 profiles) the criterion
   ladder is **unconfined 8.26e13 → strict 1.234e9 → OR-refined 5 097**
   (product census) / **4 093** (§16f leaf enumeration, the booked number).
   OR-sharing is worth **2.4e5×**; strict is worth **6.7e4×**.
3. **No middle rung exists.** The cheapest stricter reading that keeps any
   footprint-carrying pair is `confinement_keying="exact"` (the report's C3):
   it costs **15.0 h** of gate instead of 30.9 h and leaves **278 599**
   assignments instead of 4 093 — 68× more, which this endpoint's driving loop
   (13 942 → 4 093 over ten rounds) cannot close.
4. **C2 (`confinement_span_union=True`) is strictly dominated on posts_show**:
   it needs MORE probes than today (117 523 vs 111 285) and leaves 64× the
   residue (263 493 vs 4 093). §5.2 of the precision note recommended C2 as
   "the right instrument there". Measured, it is not.
5. **52.9 % of the gate's whole budget is already banked** (60 063 probes), and
   **77.3 %** of a C3 gate's budget is banked too — because one decision,
   `(Length(SYM_PARAM_id) < 16)`, is 44 % of the entire gate (48 905 of 111 285
   probes) and survives every OR-sharing criterion.
6. **Recommendation: let the gate finish as it is.** 51 222 probes remain
   ≈ **14.2 h at 1.0/s, ≈ 11.9 h at v3's 1.2/s**. Every alternative buys a
   cheaper gate by abandoning the only residue this endpoint can drive.
   *This is a recommendation, not an action — nothing was done.*

## 3. OR-SHARING ATTRIBUTION — HOW MUCH OF THE REDUCTION IS THE `classify_cells`
## LICENCE

On the one corpus, in the one currency (product census, like for like):

```
  unconfined §16b        82 637 376 644 252
  strict confinement          1 234 202 723     x 6.70e4  <- bought by STRICT
  OR-refined (today)                  5 097     x 2.42e5  <- bought by OR-SHARING
  (§16f leaf enumeration of the last row: 4 093)
```

**OR-sharing is worth 2.42e5× and strict is worth 6.70e4×.** Of the 10.2 orders
of magnitude between "confinement off" and today's booked residue, strict
supplies 4.8 and the `classify_cells` licence supplies **5.4**.

The pair-level statement is sharper than the mass-level one:

* 700 strict pairs, **2 001** OR-licensed, 931 AND-refused, 0 overlapping.
* The gate's own derivation needs **(vi) exhaustive-flip probes for 28
  decisions**. Under every strict-only reading the count is **0** — because
  **every decision representing a strict class has an EMPTY footprint**
  (42/42 under strict and strict+C3, 16/16 under strict+C2), the
  §16c "honest blind spot" case ("an empty DECIDED footprint … is (vacuously
  strictly) confined with every other confined decision"). Not one decision
  with a measured, non-empty footprint is strictly confined with anything on
  this endpoint; all 69 of them are disqualified by an OR-shared shape
  (§82.5's "overlapping 0 … refused by DISQUALIFICATION").
* So posts_show's confinement layer is, structurally, **two disjoint things**:
  a large vacuous part (700 pairs, nothing to probe, worth 6.7e4×) and the
  OR-sharing part (2 001 pairs, 111 028 of the gate's 111 285 probes, worth
  2.4e5×). The second is exactly the rule
  `CONFINEMENT_PRECISION_20260913.md` §8.3/§8.4 identified as the source of
  every surviving false licence after the currency and span corrections, and
  **100 % of it is unprobed.**

"Affordable to gate AND worth having" needs a residue the driving loop can

**There is no middle rung.** The first step down from today's criterion already

## 5. HOW MUCH OF THE GATE'S COMPLETED WORK IS REUSABLE

**Probe keys do not depend on the criterion.** `ProbeCache` keys a probe on
`(scenario, json(seeds))`; the criterion only decides WHICH probes are wanted.
Its checkpoint header is keyed on `{engine, cfg, keep, phase}` — not on the
declared list, not on the corpus digest — so a relaunch against a different
declared list reuses every recorded probe. And because
`_profile_representatives` selects reps by "carries a footprint shape on its
enabling side", a criterion that leaves a decision's footprint UNCHANGED wants
exactly the same reps (C3, or-sharing-off), and one that ENLARGES it (C2) wants
a superset. **A surviving decision's completed probes are therefore 100 %
reusable in every criterion in this table.**

Completed work, as of the v2 → v3 handover: **60 063 probe records**
(`_p26_achk_probes.ckpt.jsonl`, flushed on the v2 stop, carried over by v3).

first-appearance order and runs the chunks in order, so a finished scenario

**Recommendation: do not switch the declared list. Let
`posts-p26-gate-v3-20260914` run to completion on the 1 363 classes it has.**

**Why A, in soundness terms and not only in hours.**

1. The question posed by tonight's precision work is *"do posts_show's 2 701
   OR-sharing licences hold?"*. Options B-E answer it by **not asking** — they
   replace the licences with a criterion that licenses fewer, and none of them
   tests the ones they drop. Only A produces evidence. §16c's own rule makes A
   safe in the bad case: an inferred pair the gate FAILs or cannot verify is
   WITHDRAWN and BLOCKS (`confinement_unverified`), so a gate that refutes 76-85 %
   of classes does not leave a false 4 093 standing — it converts it into a
   larger, honest number with the offending pairs named.
2. A is also the cheapest way to reach any of B-E later. Because probe keys are
   criterion-independent, everything A records is still valid for a C3 or
   strict list afterwards; the converse is false (B discards 17 172 completed
   probes, D discards all 58 876).
3. B's 3.4 h looks attractive and is a trap: it gates the wrong thing. C3
   leaves the *strict* layer untouched (rows 5/5b are identical) — it only
   trims the OR layer from 2 001 to 815 pairs — so it buys 68× the residue in
   exchange for testing 45 % fewer of exactly the licences in question.
4. The one thing worth doing regardless, and it is free: **the 44 % of this
   gate that is one decision.** `(Length(SYM_PARAM_id) < 16)` needs 48 905 of
   the 111 285 probes and is already 78 % probed. If the coordinator wants an
   early read on whether the OR layer survives, the verdict-pass could be run
   for the classes whose two decisions are fully probed as soon as `auth_html`
   completes, instead of waiting for `anon_html`. §83.4 already filed the same
   observation ("a gate that can produce no verdict for 24 h … interleaving the
   verdict pass per class would cost nothing"). That is a change to
   `assumption_checker.py`, i.e. `src/`, so it is Bali's call, not this
   round's.

**Not acted on.** No gate was started, stopped or re-declared by this round; the
